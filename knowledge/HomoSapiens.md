# Définition

Homo sapiens est l'entité centrale du Human Knowledge Model.

Il représente le modèle biologique de référence de l'espèce humaine.

Il est indépendant de tout individu.

Il décrit ce qui est commun à tous les êtres humains.

Le patient est une instanciation particulière de Homo sapiens.

# Description

Homo sapiens est un organisme vivant multicellulaire.

Il est composé de systèmes biologiques interconnectés.

Chaque système est constitué d'organes.

Chaque organe est constitué de tissus.

Chaque tissu est constitué de cellules.

Chaque cellule est gouvernée par son génome.

---

# Les invariants

Le HKM distingue les invariants des variables.

Les invariants sont communs à tous les Homo sapiens.

Exemples :

- organisation générale du cœur

- nombre de chromosomes (cas général)

- architecture des systèmes biologiques

- organisation cellulaire

Les variables différencient les individus.

---

# Les interactions

Les systèmes biologiques ne sont jamais indépendants.

Toute modification d'un système peut influencer plusieurs autres systèmes.

Le HKM considère Homo sapiens comme un réseau dynamique.

# Philosophie

Le Human Knowledge Model décrit l'espèce.

Le Medical Digital Twin décrit un individu.

L'individu est une instanciation particulière de Homo sapiens enrichie par son histoire biologique, environnementale et médicale.
