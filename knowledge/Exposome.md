# Exposome

Version : 1.0.0

Status : Living Specification

---

# Définition

L'exposome représente l'ensemble des expositions auxquelles un individu est soumis tout au long de sa vie.

Il constitue le complément environnemental du génome.

Le Human Knowledge Model considère que le phénotype résulte de l'interaction continue entre le génome et l'exposome.

---

# Objectif

Le MDT décrit non seulement ce qu'est un individu aujourd'hui, mais également les facteurs qui ont contribué à son état actuel.

L'exposome permet de retracer cette histoire.

---

# Principe fondamental

Le génome représente le potentiel.

L'exposome représente les influences.

Le phénotype résulte de leur interaction.

# Philosophie

Le Human Knowledge Model considère que la santé est le résultat d'une interaction permanente entre :

- le génome
- le développement
- l'environnement
- l'exposome
- le temps

L'exposome constitue la mémoire des influences extérieures ayant façonné un individu.

Le Medical Digital Twin doit être capable de représenter cette mémoire afin de comprendre le passé, expliquer le présent et prédire les évolutions futures.
