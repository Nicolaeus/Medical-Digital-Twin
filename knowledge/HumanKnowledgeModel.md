# Human Knowledge Model (HKM)

Version : 1.0.0

Status : Draft

---

# Vision

Le Medical Digital Twin (MDT) ne modélise pas un patient.

Le MDT modélise Homo sapiens.

Le patient est une instance particulière du modèle général Homo sapiens.

Le Human Knowledge Model (HKM) constitue la référence scientifique du projet.

Tout le code du MDT devra implémenter le HKM.

Le HKM est indépendant de toute technologie.

Il doit rester valide indépendamment du langage de programmation, du moteur 3D ou des évolutions de l'informatique.

---

# Objectifs

Construire une représentation numérique cohérente de l'être humain permettant :

- la visualisation anatomique
- la compréhension physiologique
- l'intégration des données médicales
- la simulation
- l'aide à la décision
- l'évolution continue des connaissances scientifiques

---

# Philosophie

Le MDT ne décrit pas une maladie.

Le MDT décrit un être humain.

Une maladie est un état particulier d'un Homo sapiens.

Un traitement est une modification temporaire de cet état.

Une imagerie est une observation.

Une biologie est une mesure.

Une simulation est une prédiction.

---

# Principes fondamentaux

## Principe 1

Le modèle scientifique précède le code.

Le logiciel est une implémentation du Human Knowledge Model.

Jamais l'inverse.

---

## Principe 2

Le Human Knowledge Model est indépendant :

- du langage
- du framework
- du moteur graphique
- de la base de données

---

## Principe 3

Toutes les informations possèdent un contexte temporel.

Aucune donnée n'est intemporelle.

Toute observation possède :

- une date
- un contexte
- une méthode d'acquisition
- une qualité

---

## Principe 4

Le modèle est centré sur Homo sapiens.

Le patient est une spécialisation du modèle général.

---

## Principe 5

Toute entité possède :

- une identité
- une structure
- une fonction
- des relations
- une évolution dans le temps

---

## Principe 6

Tout est relié.

Le Human Knowledge Model est un graphe de connaissances.

Aucune entité n'existe isolément.

---

## Principe 7

Le MDT est extensible.

Toute nouvelle découverte scientifique doit pouvoir être intégrée sans remettre en cause le modèle existant.

# Le patient

Le patient n'est pas le modèle.

Le patient est une instanciation particulière d'Homo sapiens.

Le patient est défini par :

- son génome
- son développement
- son histoire
- son environnement
- son mode de vie
- ses observations
- ses traitements
- son évolution

---

# Évolution

Le Human Knowledge Model est conçu pour évoluer pendant plusieurs décennies.

Les connaissances scientifiques évolueront.

Le modèle fondamental devra rester stable.

L'objectif du MDT est de constituer une représentation numérique durable de l'être humain.
