# Anatomy

Version : 1.0.0

Status : Living Specification

---

# Définition

L'anatomie décrit l'organisation spatiale de Homo sapiens.

Elle définit l'ensemble des structures biologiques qui composent un être humain.

L'anatomie constitue le support physique de toutes les fonctions biologiques.

Aucune fonction ne peut exister sans structure.

---

# Objectif

Le Human Knowledge Model décrit l'anatomie comme un système hiérarchique organisé.

Chaque structure appartient à une structure supérieure.

Chaque structure possède :

- une forme
- une position
- une composition
- une fonction
- des relations anatomiques

# Philosophie

L'anatomie décrit ce qui existe.

Elle ne décrit pas le fonctionnement.

Le Human Knowledge Model considère l'anatomie comme le support physique sur lequel reposent toutes les fonctions biologiques.

Une structure anatomique est permanente.

Son état peut évoluer.

Sa fonction peut varier.

Sa représentation numérique constitue le socle du Medical Digital Twin.
